### [C번](https://codeforces.com/contest/2248/problem/C)

* 가중치가 제곱꼴이어서 그냥 그리디같은 게 잘 안될 것 같다.
* 그러면 기가 막힌 애드혹이거나 dp일 확률이 높은데...
* 이것저것 해보면 그냥 규칙찾기로 하기에는 경우의 수가 정말 많다는 걸 알 수 있다.
* dp를 생각해보자.
* 이전 결과를 재활용할 수 없을까?
* `dp[i]` = $i$까지의 배열에서 얻는 최대점수라 해 보자.
* 그러면 어떤 지점 $a$에서 $b$까지를 묶었을 때, `dp[a-1]`에 $(b - a + 1) ^ 2$를 더하면 된다.
* 따라서 수들 매칭 전처리만 해 두면 1차원 dp로 $O(N)$에 된다.
* 두 개를 묶는 경우랑 하나만 묶는 경우 모두를 갱신해줘야 한다.
* **분류**: dp

using namespace std;

#define all(a) a.begin(), a.end()
#define F first
#define S second

#define piii pair<int, pii>

int run() {
    int N;
    cin >> N;

    vector<ll> dp(N * 2 + 1);
    vector<int> bef(N, -1);
    vector<int> link(N * 2);

    for (int i = 0; i < N * 2; i++) {
        int now;
        cin >> now;
        now--;
        if (bef[now] == -1) {
            bef[now] = i;
        } else {
            link[i] = bef[now];
            link[bef[now]] = i;
        }
    }

    for (int i = 0; i < N * 2; i++) {
        if (link[i] > i) {
            dp[i + 1] = dp[i] + 1;
        } else {
            ll l = (i - link[i] + 1);
            dp[i + 1] = max(dp[i] + 1, dp[link[i]] + (l * l));
        }
    }

    cout << dp[N * 2] << "\n";
    return 0;
}

### [D번](https://codeforces.com/contest/2248/problem/D)

* 둘의 과반이 같으면 삭제할 수 있다.
* $a$, $b$에서 각각 선택되는 문자 종류의 가짓수는 $4$가지이다.
  * $0, 0$ / $0, 1$ / $1, 0$ / $1, 1$
* 둘이 같은 경우는 문제가 안 된다.
* 둘이 다른 경우는 그냥 없엘 수 없다.
* 다만, $0, 1$인 것과 $1, 0$인 것을 각각 하나씩 고르면 상쇄시킬 수 있다.
* 따라서, 둘을 최대한 매칭시켜 지워준다.
* 남은 것들은 $0, 0$ 또는 $1, 1$과 하나씩 매칭시키면 삭제할 수 없다.
* 매칭했는데 남은 $0, 1$이나 $1, 0$이 있으면 실패

### [E번](https://codeforces.com/contest/2248/problem/E)

* 어떤 지점에서 끊어서 이득인 경우가 있다.
* 처음에 한 생각은, 끊어서 이득인 부분이 있으면 그걸 반복하면 되는거 아닐까? 였다.
* 근데 예제를 잘 계산해보면... $I(a)$는 한 칸당 평균 $6$점이고, 끊어서 갈 때 가장 이득인 곳은 한 칸당 평균 $5.75$점이었다.
* 따라서... 단순히 반복하면 이득인 곳을 찾는 전략은 통하지 않는다.
* 그러면 어떤 지점까지'만' 진행하면 $I(a)$ 입장에서 평균이 낮아서 덜 이득인 곳을 찾아야겠다는 생각이 들었다.
* 이때 잘못 생각해버린게... 위에서 찾은 '끊어서 이득인 곳'을 적절히 반복해서 $I(a)$가 가장 손해인 곳에서 멈추게 만들어야겠다는 생각을 했다.
  * 그래서 `dp[i]` = '끊어서 이득인 곳' 을 적절히 조합해서, $I(a)$ 입장에서 인덱스 $i$인 곳에서 애매하게 멈출 때 $a$의 점수 평균의 최대... 로 놓는다는 생각을 해버렸다.
  * 이러면 이제 '끊어서 이득인 곳'들을 평균점수순으로 정렬한 다음에 적절히 갱신을 해줘야하는데, 이 갱신 자체가 복잡도가 꽤나 크다.
  * 또, 어느 시점에 멈춰야 하는지도 상당히 애매했다.
    * 마지막에는 '끊는' 연산이 필요없기 때문이다.
  * 결정적으로, $n$ 제한이 $10$억이어서 애초에 불가능하다.
* 따라서 이 풀이를 폐기했다...
* 이제 여기서, 마지막에 '끊는' 연산이 필요없다는 부분을 열심히 생각해봤다.
* 그러고 나서, 다음과 같은 생각을 했다.
  * 어느 구간 $i$에서 끊은 다음, 처음부터 쭉 가서 다시 $i$에 도달했다고 하자.
  * 이때 '끊는' 연산이 이득인 경우는 어떤 경우일까?
  * $[0, i]$의 이득이 $[i+1, 2i]$의 이득보다 큰 경우이다.
  * 그런데, 이런 경우는 '끊는' 연산을 2번째로 하기도 전에 이미 $I(a)$보다 $a$의 점수가 커야 한다.
  * 반대로, $[i+1, 2i]$의 점수가 더 큰 경우라면, '끊는' 연산을 할 필요가 없다.
  * 아니 그러면, 한번만 끊어도 충분한거 아닌가?
* 그래서 최대 한번만 끊는다고 생각하고 풀이를 짰다.
* 마지막에 멈추는 위치는 $a$ 입장에서 점수를 추가로 얻는 부분이어야 이득이므로, $p$에 존재하는 인덱스만 생각해도 된다.
* 이건 끊는 위치에서도 똑같이 적용된다.
* 따라서, $O(M^2)$에 풀 수 있다.
* for문 범위 잘못잡아서 30분을 추가로 날렸다...
* **분류**: 그리디

#include <bits/stdc++.h>

using namespace std;

#define all(a) a.begin(), a.end()
#define F first
#define S second
#define INF 0x3f3f3f3f
#define MOD 998244353
#define ll long long
#define pii pair<int, int>
#define piii pair<int, pii>

long long N, M, d;
vector<long long> pv, qv;
vector<ll> qcsum;
ll get(ll tar) {
    int idx = lower_bound(all(pv), tar + 1) - pv.begin();
    // cout << idx << endl;
    return (tar + 1) * d + qcsum[idx];
}

int run() {
    cin >> N >> M >> d;
    ll base = 0;

    pv = vector<long long>(M);
    qv = vector<long long>(M);
    qcsum = vector<ll>(M + 1);
    for (int i = 0; i < M; i++) {
        cin >> pv[i] >> qv[i];
        pv[i]--;
    }
    for (int i = 0; i < M; i++) {
        qcsum[i + 1] = qcsum[i] + qv[i];
    }
    base = (ll)d * N + qcsum[M];

    for (int i = 0; i < M; i++) {
        // pv[i]다음에서 리셋
        ll nows = get(pv[i]);

        // pv[j]발자국씩 추가로가기
        // 0부터 시작, 반대쪽은 pv[i]+2부터
        for (int j = 0; j < M; j++) {
            ll news = nows + get(pv[j]);
            ll newothers = 0;
            ll idx = pv[j] + pv[i] + 2;
            while (idx >= N) {
                // cout << "asdf" << " " << pv[i] + pv[j] + 2 << endl;

                idx -= N;
            }
            newothers += get(idx);

            // cout << i << " " << j << " " << nows << " " << news << " "
            //      << newothers << endl;
            if (news > newothers) {
                cout << "YES\n";
                return 0;
            }
        }
    }

    cout << "NO\n";
    return 0;
