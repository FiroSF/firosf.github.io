## 개요

백준 1981 배열에서 이동 문제의 풀이과정과 정답 코드를 다룬다.  
글 처음써봄

> [문제 링크](https://www.acmicpc.net/problem/1981)  
> $n \times n$짜리의 배열이 하나 있다. 이 배열의 $(1, 1)$에서 $(n, n)$까지 이동하려고 한다. 이동할 때는 상, 하, 좌, 우의 네 인접한 칸으로만 이동할 수 있다.  
> 이와 같이 이동하다 보면, 배열에서 몇 개의 수를 거쳐서 이동하게 된다. 이동하기 위해 거쳐 간 수들 중 최댓값과 최솟값의 차이가 가장 작아지는 경우를 구하는 프로그램을 작성하시오.

## 1. 접근

최대 숫자가 $200$이고, 배열이 최대 $100 \times 100$이니 제한이 꽤나 넉넉한 편이라고 생각했다. 그러나 모든 (상한, 하한) 쌍을 탐색하기에는 시간복잡도가 꽤나 커지기 때문에 불가능해 보였다. 따라서 다음과 같이 생각했다.

* 상한$=200$과 하한$=0$을 지정한다.
* 처음에 길찾기를 진행한 뒤 상한을 $1$씩 줄여가며, 길찾기에 실패할 때까지 반복적으로 탐색한다.
* 이렇게 해서 나온 결과는 하한이 $0$일 때 $(\text{최대} - \text{최소})$가 가장 작은 경우이다. 이걸 저장해 준다.
* 상한과 하한을 $1$씩 늘려서, 하한이 $200$이 될 때까지 2번 과정을 다시 반복한다.

4번에서 상한과 하한을 같이 $1$씩 늘리는 이유는, 현재 찾은 $(\text{최대} - \text{최소})$값보다 더 작은 값이 아니면 찾는 의미가 없기 때문이다. 다음 루프에서 상한과 하한의 간격을 이전과 유지하고, 길찾기에 성공하면 $(\text{최대} - \text{최소})$값을 새로 업데이트해준다.

## 2. 코드

{% raw %}
```cpp
// https://www.acmicpc.net/problem/1981
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

vector<pair<int, int>> DIRECTIONS{{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

int N;
vector<vector<int>> board;
vector<vector<bool>> reserved;

// BFS
bool find(int lowerBound, int upperBound) {
    if (lowerBound > board[0][0] || board[0][0] > upperBound) {
        return false;
    }

    // Clean board
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            reserved[i][j] = false;
        }
    }

    queue<pair<int, int>> reservation;
    reservation.push(make_pair(0, 0));
    reserved[0][0] = true;
    while (!reservation.empty()) {
        int r = reservation.front().first, c = reservation.front().second;
        reservation.pop();

        for (int i = 0; i < 4; i++) {
            int newr = r + DIRECTIONS[i].first, newc = c + DIRECTIONS[i].second;
            if (0 <= newr && newr < N && 0 <= newc && newc < N && !reserved[newr][newc]) {

                int target = board[newr][newc];
                if (lowerBound <= target && target <= upperBound) {
                    // If found
                    if (newr == N - 1 && newc == N - 1)
                        return true;
                    reserved[newr][newc] = true;
                    reservation.push(make_pair(newr, newc));
                }
            }
        }
    }

    return false;
}

int main() {
    cin >> N;

    board = vector<vector<int>>(N, vector<int>(N));
    reserved = vector<vector<bool>>(N, vector<bool>(N, false));

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            int t;
            cin >> t;
            board[i][j] = t;
        }
    }

    int upperBound = 200, lowerBound = 0, minimum = 1234567890;
    while (lowerBound < 200) {
        while (find(lowerBound, upperBound)) {
            upperBound--;
        }

        minimum = min(minimum, upperBound - lowerBound + 1);
        lowerBound++;
        upperBound++;
    }

    cout << minimum << "\n";
}
```

## 3. 고찰

다른 분들의 코드를 보니, 하한으로 for문을 돌리고 각 하한마다 상한을 이진 탐색으로 찾는 방식이 많았다. 상한을 $200$과 하한의 중앙값으로 설정한 뒤 길찾기를 진행하고, 실패하면 중앙값보다 큰 값을 상한으로, 성공하면 중앙값보다 작은 값을 상한으로 하는 방식이다. 이 문제에서는 숫자 범위가 $0 \sim 200$이어서 이진 탐색 없이도 푸는 것이 가능했다.
